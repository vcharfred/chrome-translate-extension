# AI 网页翻译（Chrome 扩展）

整页翻译 + 划词翻译，支持三种大模型服务商，密钥由扩展私有存储保管，不暴露给任何网页。

## 功能

- **整页翻译**（核心）：一键把当前网页正文全部替换成译文，右下角进度条实时显示；支持「显示原文 / 译文」切换、「恢复原文」一键还原。
- **划词翻译**：选中文字后出现"译"按钮，点击弹出翻译面板（ESC 或 ✕ 关闭，支持一键复制）。
- **右键菜单**：选中文本 → 右键 →「翻译选中文本」。
- **弹窗翻译**：点击工具栏图标，可直接粘贴文本翻译。
- **多服务商**：DeepSeek / 阿里云百炼（通义千问）/ 腾讯混元，三家的 OpenAI 兼容接口均已内置。
- **多语言**：可设置目标语言（简中/繁中/英/日/韩/法/德/俄/西）。
- **主口令加密**（可选）：API Key 以 AES-256-GCM 密文落盘，口令不保存，忘记只能重置。

## 整页翻译怎么用

三种入口，效果相同：

1. 点击工具栏插件图标 → **🌐 翻译整个网页**
2. 网页空白处右键 → **翻译整个网页**
3. （划词仍走原来的悬浮"译"按钮，互不干扰）

控制条按钮：**显示原文/译文** 切换、**恢复原文** 还原并关闭、✕ 停止（已翻译的部分保留）。

### 实现要点

- **节点筛选**：TreeWalker 遍历文本节点，跳过 `script / style / code / pre / textarea / svg / iframe`、`display:none` 等不可见元素、纯数字符号文本，以及带 `translate="no"` 或 `.notranslate` 的区块。
- **批量并发**：按 1200 字符 / 25 段一组打包，3 路并发请求，逐批返回即就地替换DOM（渐进渲染，不用等全部完成）。
- **结构化输出**：后台把数组序列化成 JSON 让模型翻译并**严格返回同长度 JSON 数组**；解析时容忍 ```json 代码块、前后废话，长度不匹配或解析失败自动重试一次。
- **结果校验**：条目数不符直接判失败，不做错位替换（宁可漏翻也不翻错行）。
- **去重缓存**：同一页面内重复文本只翻译一次，省 token。
- **未知 DOM 安全**：只改文本节点的 `nodeValue`，不动标签结构、不注入 HTML，避免破坏页面布局与脚本。

## 降低 token 消耗（v1.3）

整页翻译一次 0.04 元这类开销，主要来自三处浪费，已逐项优化：

| 优化项 | 说明 | 预期效果 |
|---|---|---|
| **智能正文（默认开启）** | 跳过 `nav / footer / aside`、面包屑、分页、Cookie 条、侧栏等非正文区域 | 通常减少 **40%~60%** 文本量（导航+页脚常占整页一半以上） |
| **语言跳过** | 已是目标语言的段落（如目标为中文时的纯中文段落）直接不发请求 | 中英混排站点省 10%~30% |
| **结果缓存** | 按「目标语言 + 模型 + 原文」哈希缓存**每一段**译文，跨页面、跨会话复用；缓存里只有 hash→译文，**不含 URL 和页面快照** | 再次访问同一页面接近 0 成本；**页面改了几段就只重翻那几段** |

**缓存是持久化的**（存在本机扩展存储，关闭浏览器仍保留），但有硬性上限：**最多 4000 条 / 4 MB**，超出自动淘汰最旧的条目，不会无限增长（Chrome 对 `storage.local` 的硬配额是 10 MB，4 MB 留有余量）。运行期内存占用可忽略：内容脚本只在页面内维护一个去重 Map，随页面关闭释放。设置页可实时看到「N 条 · X KB」，也可一键清空或**完全关闭缓存**（关闭后不落盘任何译文）。
| **更大批次** | 单批 1200 → 1800 字、25 → 40 条 | 请求数减少约 1/3，系统提示重复开销同步下降 |
| **整页专用模型** | 设置页可为整页翻译单独选低价模型 | 换 `qwen-turbo` / `hunyuan-lite` 单价可再降一档 |
| **同页去重** | 重复文本（导航、页脚常见）只翻译一次 | 视页面而定 |

实测口径：控制条现在会显示 `完成 N 段 · M 字 · K 次请求 · 缓存命中 X 段`，可以直接对比优化前后的请求数与字数。

想更省的做法：
- 整页翻译用 `qwen-turbo` 或 `hunyuan-lite`，划词翻译保留 `deepseek-chat`（两者可在设置页分别指定）。
- 只需要看大意时，用**划词翻译**而非整页翻译。
- DeepSeek 自带 prefix 缓存：本扩展的 system prompt 固定，多批并发请求可命中缓存价（输入更便宜）。

### 已知限制

- 动态渲染（如无限滚动、SPA 路由切换）后新增的内容不会自动翻译，需再点一次。
- 长文会消耗较多 token，建议在设置里选 `qwen-turbo` / `hunyuan-lite` / `deepseek-chat` 等低价模型；可用「取消记住 + 会话模式」配合控制成本。
- 遇到 429 限流时进度条会显示"N 批失败"，稍后重试即可。

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`。
2. 打开右上角「开发者模式」开关。
3. 点击「加载已解压的扩展程序」，选择本文件夹（`chrome-translate-extension`）。
4. 点击工具栏的插件图标 →「设置」，选择服务商、填入 API Key、保存并测试连接。

Edge 浏览器同样适用：`edge://extensions/` → 开发者模式 → 加载解压缩的扩展。

## API Key 安全设计

1. **存储隔离**：Key 保存在 Chrome 为本扩展分配的 `chrome.storage` 私有存储中。浏览器按扩展 ID 严格隔离该存储——普通网页的 JS 无法访问，其他扩展也无法访问，页面源代码里永远看不到 Key。
2. **密钥不出后台**：所有对大模型 API 的请求都在扩展后台（Service Worker）中发起；内容脚本只负责选词和展示，与后台仅交换"待翻译文本"和"译文"，**任何代码路径都不会把 Key 传给网页**。
3. **最小权限**：`host_permissions` 仅声明三家 API 域名；不申请 `scripting`、`tabs`（读取内容）等高危权限；MV3 禁止远程代码加载，全部代码本地运行、可审查。
4. **会话模式（推荐高安全需求用户）**：设置页可取消「在浏览器中记住 API Key」，Key 将只写入 `chrome.storage.session`，**关闭浏览器即自动清除**。
5. **诚实提示**：没有任何软件能防御"本机恶意程序直接读取浏览器磁盘文件"这类攻击。若公用电脑或不信任当前环境，请使用会话模式，或翻译完成后清除 Key。
6. 翻译缓存里只有**网页正文与译文**，**不含 API Key**；若在意本机留存浏览内容，可在设置页关闭缓存或随时清空。

## 主口令加密（可选，推荐）

设置页第 3 节勾选「启用主口令加密」并设定口令即可。工作机制：

- 密钥派生：PBKDF2-HMAC-SHA256，20 万轮迭代，16 字节随机 salt
- 数据加密：AES-256-GCM，12 字节随机 IV，自带认证标签（口令错误会直接解密失败）
- 落盘内容：`{salt, iv, data, iter}` 的 base64 密文，**磁盘上不存在明文 Key**
- 解锁后明文只放在 `chrome.storage.session`（**仅在内存，不落盘**），关闭浏览器自动锁定
- 口令本身**从不存储**，因此**忘记口令无法找回**——只能点「忘记口令 · 重置」清空密文，然后重新填写 API Key、设置新口令

状态机：未启用 →（设口令）→ 已解锁 ⇄（关闭浏览器 / 立即锁定 / 输入口令）→ 已锁定 →（忘记口令）→ 回到未启用。

> 会话模式（不记住 Key）与口令加密可二选一或叠加：前者不落盘任何东西，后者落盘但只有密文。

## 文件结构

```
chrome-translate-extension/
├── manifest.json    # MV3 配置：权限、入口声明
├── background.js    # 后台：API 调用、密钥与口令管理、右键菜单（密钥只在这里出现）
├── crypto.js        # PBKDF2 派生 + AES-256-GCM 加解密（仅后台 importScripts 加载）
├── content.js       # 内容脚本：划词检测、悬浮按钮、结果面板
├── content.css      # 内容脚本样式（aitx- 前缀隔离）
├── options.html/js/css  # 设置页：服务商、Key、模型、目标语言、连接测试
├── popup.html/js    # 工具栏弹窗：状态、开关、快捷翻译
└── icons/           # 插件图标
```
